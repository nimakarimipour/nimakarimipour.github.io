Annotator  Java

2023

Automated tool that integrates NullAway into existing codebases by inferring and applying nullability annotations at scale.

  • Instantly generates patches with no remaining checker errors, applying suppressions where annotations alone cannot resolve them.
  • Supports large-scale projects incrementally, target by target; scaled to fully integrate NullAway across Uber’s entire monorepo.
  • Recognized with a dedicated blog post by Gitar: Automating Java Codebase Annotations for Null Safety.

NullAway  Java

2022

A fast, practical null pointer checker for Java, built as an Error Prone plugin. Core contributor with type inference extensions.

  • Enhanced to support expressing method preconditions and postconditions.
  • Added a serialization service to log errors and compute quick-fix suggestions for errors reported by the checker.

TaintTyper  Java

2024

A practical type-based taint checker and inference tool for Java, exceeding recall of state-of-the-art whole-program taint analyzers.

  • Modular and incremental checking for better scalability and performance.
  • Automatically infers tainting type qualifiers, including polymorphic and generic type argument annotations.
