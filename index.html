    Ph.D. Research Intern

    Uber Technologies · Programming Systems Group (PSG)

    Worked on enhancing Annotator to work at monorepo scale. Used internally at Uber, Annotator has annotated millions of lines of code, bringing an entire Java monorepo onto NullAway.

    Annotator simplifies and accelerates the adoption of NullAway in existing codebases. By automating the search for a set of annotations that minimizes reported NullAway errors, it streamlines onboarding projects to NullAway. Once executed, Annotator can bring code to a state where no NullAway errors are reported, enabling immediate integration. For cases where errors cannot be fully resolved with annotations alone, it automatically applies suppression annotations. It also considers build target boundaries and can be configured to avoid adding annotations that might trigger errors in downstream dependencies, so large projects can adopt NullAway incrementally, target by target.

    Featured in Automating Java Codebase Annotations for Null Safety by Gitar.
